# TianMind Services · Public-Safe Service Catalog

TianMind Studio / 天智工坊 is an AI-assisted full-stack studio for practical demos, service pages, internal tools, local-first knowledge workflows, public-safe GitHub assets, and verification-first handoff.

天智工坊把模糊想法、业务流程、材料和工具需求，整理成可打开、可验证、可交付的 demo、页面、脚本、README、案例和交付包。

## What This Repository Is

This repository is the public service catalog for TianMind Studio. It helps outside readers understand:

- What TianMind Studio can build.
- Which public pages, demos, and templates can be reviewed first.
- How to prepare a safe first brief.
- Which evidence should exist before a project moves deeper.
- What must stay private.

这个仓库只放公开安全的服务说明和评估入口，不放客户资料、私有业务记录、内部系统配置或未确认事实。

## How To Start Safely

Start with public-safe context:

- Desired outcome.
- Target user or reader.
- Current public link, redacted sample, or screenshot with private details removed.
- Preferred delivery shape: page, demo, script, README, workflow, or handoff pack.
- Review date or launch window.
- What must stay private.

Use the public brief template:

- Project brief: <https://junius.tianmind.com/brief.html>
- English buyer brief: <https://junius.tianmind.com/templates/english-buyer-brief-template.md>

## What Comes Back

A first public-safe package should usually include:

- A short scope sheet.
- A working page, demo, script, README, or template.
- A verification path: command, screenshot, checklist, URL, or static output.
- A handoff note with acceptance evidence.
- A boundary statement explaining what was not exposed.

## Public-Safe Boundary

Do not put these in public issues, README files, public pages, screenshots, or this repository:

- No customer files.
- No raw private conversations.
- No credentials, tokens, cookies, SSH keys, or account access.
- No contracts.
- No sensitive commercial records.
- No private backend access.
- No database dumps.
- No full private vault content.
- No Hermes or safe-index configuration.
- No unconfirmed claims.

Use public links, redacted samples, sanitized screenshots, sample outputs, and verification commands instead.

## Verification

The public showcase that supports this service catalog is checked by:

```bash
npm run test:public-showcase
```

The verifier checks required files, local links, sitemap coverage, catalog entries, AI-readable brief coverage, high-risk secret-like patterns, public boundary markers, and public-safe copy coverage.
